# StudyFlow – AI Student Productivity Assistant

StudyFlow is an Agentic AI Student Productivity Assistant that helps students organize assignments, exams, study sessions and academic deadlines.

## Main Features

- AI-powered study planning
- Assignment and task management
- Exam management
- Calendar with monthly, weekly and daily views
- Adaptive rescheduling for missed sessions
- Notifications
- Progress tracking
- Agent activity and monitoring
- Authentication and user-specific persistent data

## Agentic Workflow

Student Request → AI Agent → Planning/Reasoning → Tool Selection → Tool Execution → Verification → Updated Schedule → Student Response
